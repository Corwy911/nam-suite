First launch (the apps are not signed by Apple)

macOS blocks the first launch of an app that was downloaded and is not signed. Once: right-click the app → Open → Open. Or, in Terminal: xattr -dr com.apple.quarantine "/Applications/NAM Suite".

NAM Capture asks once for permission to use the audio input (the interface you calibrate): allow it.

Uninstall

Open Disinstalla NAM Suite in /Applications/NAM Suite: it counts what you would lose, asks, and removes everything.
